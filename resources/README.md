# Course documents and authoritative locations

[Course homepage](../README.md) · [Assessment guide](../docs/ASSESSMENT_OVERVIEW.md) · [Source alignment](../docs/SOURCE_ALIGNMENT.md)

The **current Deep Learning course documents are distributed through Canvas**: the 2026/27 Simplified Handbook, 27-slide Key Information Student Briefing, complete handbook, teaching announcements and assessment clarifications.

The PDF retained here, [`2026_2027_DL_Final_Project_Handbook_Shared.pdf`](2026_2027_DL_Final_Project_Handbook_Shared.pdf), is an **earlier 51-page full handbook**. Its rules differ from the newly supplied 10 November simplified handbook and briefing for Part B group size and maximum bonuses. The simplified handbook says the full handbook takes precedence if wording differs; obtain a definite ruling from the module team on Canvas. **Do not assume this older PDF is the most recently approved assessment specification.**

The new documents were reviewed to update GitHub’s student-facing guidance, but their PDFs have not been uploaded to this repository in this update. For a direct student-facing copy, use the module’s Canvas version.

For student preparation: [Getting started](../docs/GETTING_STARTED.md) explains repository and dataset setup; [Part A guide](../docs/COURSEWORK_GUIDE.md) provides the supported experimental workflow; [Part B guide](../docs/PART_B_GUIDE.md) summarises the newer group-project brief. All assessed work and queries about marking belong in Canvas or the designated module teaching channels.
